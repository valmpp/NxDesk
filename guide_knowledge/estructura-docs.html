02 · Estructura docs/

La memoria técnica
de cada proyecto

Una estructura de docs/ que funciona para cualquier stack. Se copia al repositorio de cada proyecto nuevo y se mantiene viva durante todo el ciclo de vida.

Filosofía: docs/ no es un almacén de archivos — es la memoria técnica, operativa y funcional del proyecto. Si algo ocurrió y no está en docs/, para el equipo siguiente no ocurrió.

10 reglas del sistema documental

01
Documentar el porqué, no solo el qué
Si una decisión técnica puede generar dudas a futuro, va como ADR. El código dice qué — la documentación dice por qué.
02
Todo problema importante termina en KB
El ciclo es: BUG/INC → resolución → KB. Sin KB, el aprendizaje se pierde en la siguiente rotación de equipo.
03
Diferenciar mitigación de solución definitiva
Un workaround no es una solución. Se documenta como mitigación y el issue queda abierto hasta causa raíz confirmada.
04
La KB debe ser accionable
Cuándo usarla, diagnóstico, pasos, resultado esperado, qué no hacer y rollback. Una guía que no da el resultado esperado no sirve.
05
Markdown para conocimiento — HTML para lo visual
Arquitectura, ADR, BD, APIs, incidentes → Markdown. Mockups, walkthroughs, flujos interactivos → HTML en 09-visual-docs/.
06
Los documentos se enlazan entre sí
Bugs → KB que generaron. Módulos → sus flujos. Flujos → sus integraciones. La documentación es una red, no una lista de archivos.
07
Nunca secrets reales en docs/
Solo se documenta qué variables existen, no sus valores. Las credenciales reales van en Vault o en variables de entorno del servidor.
08
Encabezado ISO en todo documento
Código, versión, fecha, autor e historial de cambios. Sin encabezado, el documento no está bajo control documental.
09
Actualizar cuando cambia el sistema
Si cambió el código que afecta un flujo documentado, el documento sube de versión en el mismo PR. Código actualizado con docs desactualizadas = deuda.
10
La documentación crece con el proyecto
No es tarea final del proyecto — es continua. Cada cambio relevante, incidente o decisión nueva alimenta el sistema.
